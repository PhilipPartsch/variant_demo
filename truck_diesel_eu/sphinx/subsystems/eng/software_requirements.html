Software requirements¶

Software requirements (swreq) of the Engine Interface (ENG), each refining an architecture element. Workflow stage swreqs, stream eng. The whole folder exists only in diesel products.

Software Requirement: Report filtered fuel level SWREQ_ENG_FUEL_LEVEL_REPORT
status: draft
refines: ARCH_ENG_FUEL_LEVEL
implements_back: IMPL_ENG_FUEL_LEVEL_REPORT
verifies_back: TEST_ENG_FUEL_LEVEL_REPORT

The ENG software shall report the fuel level as the 10 s average of the tank level sensor in percent of the tank capacity, rounded to 1 %.
Software Requirement: Send engine torque limit SWREQ_ENG_TORQUE_LIMIT
status: draft
refines: ARCH_ENG_TORQUE_INTERFACE
implements_back: IMPL_ENG_TORQUE_LIMIT
verifies_back: TEST_ENG_TORQUE_LIMIT

The ENG software shall send the torque limit, calculated as the traction power limit divided by the current engine speed, in a TSC1 message every 10 ms.
