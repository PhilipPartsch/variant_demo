Software requirements¶

Software requirements (swreq) of the Charging Controller (CHG), each refining an architecture element. Workflow stage swreqs, stream chg. The whole folder exists only in battery-electric products.

swreq Start session only with locked inlet SWREQ_CHG_SESSION_START ¶
Details
statusdraft
refinesARCH_CHG_SESSION_CONTROL
gapsGAP_SWREQ_CHG_SESSION_START_REVIEW__BUS_BEV_LFP_EU
implements_backIMPL_CHG_SESSION_START
verifies_backTEST_CHG_SESSION_START

The CHG software shall start a charging session only while the CCS inlet is reported as locked.

swreq Limit charging current SWREQ_CHG_CURRENT_LIMIT ¶
Details
statusdraft
refinesARCH_CHG_SESSION_CONTROL

implements_backIMPL_CHG_CURRENT_LIMIT
verifies_backTEST_CHG_CURRENT_LIMIT

The CHG software shall request a charging current of at most the maximum charging power divided by the nominal pack voltage of the product.

The CHG software shall halve the requested charging current while the contact temperature of the charging interface exceeds 90 °C.
