System overview
===============

The CV platform consists of four subsystems. Which of them a product contains
depends on its powertrain.

======================================  =========  ==============================
Subsystem                               Products   Integration
======================================  =========  ==============================
Vehicle Control Unit (VCU)              all        own docs and C code
Charging Controller (CHG)               BEV        own docs and C code
Engine Interface (ENG)                  diesel     own docs and C code
Battery Management System (BMS)         BEV        imported needs (external)
======================================  =========  ==============================
