Architecture¶

Architecture elements (arch) of the Charging Controller (CHG), each satisfying vehicle requirements. Workflow stage archs, stream chg. The whole folder exists only in battery-electric products.

Architecture: High-power charging interface ARCH_CHG_INLET
status: draft
satisfies: REQ_MAX_CHARGE_POWER, REQ_PANTOGRAPH_CHARGING
refined_by: SWREQ_CHG_INTERFACE_DERATING, SWREQ_CHG_PANTOGRAPH_SEQUENCE
affected_by: DEC_CHARGING_INLET_PRIORITY
gaps: GAP_ARCH_CHG_INLET_REVIEW__BUS_BEV_LFP_EU

The high-power charging interface is a vehicle-mounted roof pantograph (SAE J3105-2) that is raised at the charging stop, rated for the charging power of REQ_MAX_CHARGE_POWER.
Architecture: CCS inlet and charging session ARCH_CHG_SESSION_CONTROL
status: draft
satisfies: REQ_EU_CHARGING_STANDARD
refined_by: SWREQ_CHG_CURRENT_LIMIT, SWREQ_CHG_SESSION_START
gaps: GAP_ARCH_CHG_SESSION_CONTROL_REVIEW__BUS_BEV_LFP_EU

The CCS inlet is a CCS2 vehicle inlet (IEC 62196-3). The charging session control runs the session with the charger over ISO 15118-2 and sets the charging current limit from the BMS cell limits.
